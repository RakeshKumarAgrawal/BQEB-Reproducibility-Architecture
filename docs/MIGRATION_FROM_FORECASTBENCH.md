# Migration from ForecastBench

## Why this repository is separate

This package is for the BQEB reproducibility architecture manuscript. It is separate so that an architecture contribution, its evidence boundaries, and its manuscript lineage are not conflated with a benchmark implementation paper.

## Relationship

```text
BQEB-Reproducibility-Architecture
|
+---- enables future modules

BQEB-ForecastBench
|
+---- benchmark implementation paper
```

The repositories may be cross-referenced after publication, but they must retain separate release identities, metadata, evidence scope, and publication records.
