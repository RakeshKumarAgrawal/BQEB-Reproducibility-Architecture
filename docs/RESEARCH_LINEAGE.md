## Lineage Principles

### Maintain Separation

Each generation maintains distinct DOI identifiers:
- **Architecture DOI (10.5281/zenodo.22291930):** Framework, tools, validation mechanisms
- **Benchmark DOI (10.5281/zenodo.21735978):** Datasets, experiments, empirical results

This separation ensures:
- Clear scholarly attribution
- Traceable research dependencies
- Proper citation guidance
- Extensibility for future work

### Reference Path

Future BQEB research should:

1. Reference the **Architecture DOI** when adopting reproducibility framework
2. Reference the **Benchmark DOI** when using datasets or experimental procedures
3. Create **new DOIs** for original contributions within each generation
4. Document **lineage connections** in publication metadata

### Evidence Traceability

Each generation documents its connection to previous generations through:
- Explicit DOI citations
- Manuscript acknowledgments
- Supplementary materials cross-references
- Research metadata documentation

This creates an auditable chain of research contribution and scholarly integrity.
