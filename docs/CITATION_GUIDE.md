## Citation Policy

### When to cite Architecture DOI (10.5281/zenodo.22291930)

Cite the architecture DOI when:

- Referencing the reproducibility framework or design principles
- Implementing validation workflows based on this architecture
- Discussing reproducibility-first methodologies
- Using artifact integrity validation mechanisms
- Extending governance or evidence traceability mechanisms

### When to cite Benchmark DOI (10.5281/zenodo.21735978)

Cite the benchmark DOI when:

- Referencing benchmark datasets or experimental results
- Comparing forecasting model performance
- Extending ForecastBench experiments
- Using benchmark-specific data or procedures
- Evaluating smart-grid forecasting approaches

## Citation Accuracy

Maintaining separate DOI citations ensures:

- **Research lineage clarity** — distinguishes framework from benchmarks
- **Scholarly integrity** — proper attribution to distinct artifacts
- **Future extensibility** — enables tracing contributions through research generations
- **Reproducibility tracking** — documents which systems and datasets were used

Please cite both DOIs when your work leverages both the architecture framework and benchmark experiments.
